# Returns

## Return labels
A return label is created in the portal under Shipments, Create return. The label is valid for 30 days. It can be sent to the recipient by email as a PDF or as a QR code that a parcel shop prints.

## Return pricing
A return is billed at the Economy rate minus 10 percent. The account is charged only when the return label is scanned for the first time; unused labels cost nothing.

## Return Hub consolidation
Accounts with the Return Hub option do not receive returns one by one. Returns are collected at the hub and delivered together once a week, on Thursday.

## Refused parcels
A parcel that the recipient refuses at the door is returned to the sender automatically. The return leg is billed at the Standard rate, not at the reduced return rate.
